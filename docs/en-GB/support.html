Support

If you have a question or run into a problem while using LectureQ, please check the answers below first. If that doesn’t solve it, just send us an email.

Getting Started

How do I jot down a question quickly?

Click the blue Add Question button in the toolbar, or press ⌘ ⇧ N at any time.

  • The Time field fills in with the current time automatically. You can edit it in HH:mm (24-hour) format, and clicking Now sets it back to the current time.
  • Return to save · ⌘Return to save and keep typing · Esc to cancel
How do I create or switch lectures?

Use the lecture menu on the left of the toolbar to pick a lecture, add a new one, import one from Markdown, or delete the current lecture.

To rename a lecture, click its title at the top of the middle column and edit it right there.

What does the ? next to a question mean?

In the question list on the left

  • ? Orange outline = a question you haven’t resolved yet
  • ? Solid green = a resolved question
  • Click the ? to switch between resolved and unresolved. Turn on Unresolved Only in the toolbar to see only the questions you haven’t resolved.

On the time block’s vertical line

  • The colour shows whether it’s resolved (orange / green), and a solid circle means an answer has been written.
  • Click the ? to jump to that question.

Organising

How are time blocks and questions connected?

A lecture can have several time blocks. A new block starts at the time you create it, and the previous block is adjusted to end at that time.

  • Each question appears as a ? on the vertical line of the block that matches its time (or the time it was written, if it has none).
  • If a question’s time doesn’t fall inside any block, a block covering that time is created automatically.
  • Use Settings at the top right of a block to change its colour, start time or duration, or to delete it. Once you delete a block yourself, automatic block creation stops for that lecture (so deleted blocks don’t come back).
What are follow-up questions?

They are questions that branch off from another question. Type one into the Follow-up questions field in the question details and press Return to create it, or use Link an Existing Question as a Follow-up to connect a question you already have.

In the list on the left, follow-ups are indented under the original question, and in the graph they are connected by arrows. Unlink only removes the connection; it doesn’t delete the question.

What’s the difference between “Resolved” and “What I Learnt”?

When you tick Resolved in the question details, you can choose whether to Include in What I Learnt.

The “What I Learnt” section of the Summary gathers only questions that are resolved and included. You can also choose with Exclude / Add Back in the summary, and the answer is always kept.

Where do I find the summary, graph, time blocks and learning status?

They’re all in the View menu in the toolbar.

  • ⌘1 Summary — questions to ask, what you learnt and your notes, all at a glance
  • ⌘2 Graph — a map of how your questions relate. Click a node to go to that question, pinch or use − / + to zoom, and click the % to fit it to the window
  • ⌘3 Time Blocks — the blocks from every lecture in chronological order
  • ⌘4 Learning Status — Where I Am Now · Where I Want to Be When Done · What I Want to Learn
How do I find answers with AI?

In the question details, choose a step from the Copy AI Prompt menu to the right of the “Answer” heading. A prompt filled in with the lecture name, your notes from that point, your learning status and the original question is copied to the clipboard. Paste it into whichever AI chat you use.

  • Refine the Question → Find the Answer → Question the Answer → Draw Out Follow-ups → Get My Answer Graded
  • Get My Answer Graded is available only once you’ve written something in your own words in the answer field.
  • The app never talks to AI services directly. You do the copying and pasting yourself.

For more detail, see the Guide: Find Answers with AI.

How do I import a conversation saved as Markdown (.md)?

Choose a file from lecture menu → Import from Markdown… and it becomes a new lecture. The original file is only read, never changed.

# Lecture title
## Topic 1
**Me** — First question (original question)
**AI** — Reply (becomes the answer and is marked resolved)
**Me** — Next question (follow-up question)
  • The first speaker in the file is treated as the person asking; anything said by other speakers becomes the answer to the preceding question.
  • In each ## section, the first question is the original question and the ones after it are its follow-ups.

Settings & Data

I want to change the text size.

Adjust it in View → Text Size. ⌘+ Larger · ⌘- Smaller · ⌘0 Default Size (85% to 200%). Your choice is remembered.

How do I delete a question or a lecture?
  • Question: Control-click the question in the list on the left → Delete
  • Lecture: lecture menu → Delete Current Lecture (this also deletes the lecture’s questions and blocks)

Deleting can’t be undone, so please back up anything important first, as described below.

Where is my data stored? How do I back it up?

All your data is stored only in the following folder on this Mac and is never sent off the device.

~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/

  • Back up: quit the app, then copy the whole folder (including the -wal and -shm files that sit next to LectureQ.store).
  • Reset: quit the app, then delete this folder. Moving the app to the Bin alone doesn’t remove it.
System requirements · How do I build it from source?

LectureQ runs on macOS 14 or later.

To build from source, clone the repository and run ./run.sh, or run xcodegen generate and then open LectureQ.xcodeproj in Xcode and run it. See the GitHub repository for details.
