サポート

LectureQの使い方でわからないことや困ったことがあれば、まずは下記をご確認ください。解決しない場合は、メールでご連絡ください。

はじめに

質問をすばやく書き留めるには？

ツールバーの青い質問を追加ボタンを押すか、いつでも ⌘ ⇧ N を押してください。

  • 時点欄には現在の時刻が自動で入ります。HH:mm（24時間制）の形式で書き換えられ、いまを押すと現在の時刻に戻ります。
  • Return 保存 · ⌘Return 保存して続ける · Esc キャンセル
講義を作成したり切り替えたりするには？

ツールバー左側の講義名のメニューから、講義を選ぶ、新しい講義を追加する、Markdownから読み込む、現在の講義を削除する、といった操作ができます。

講義名は、中央の列のいちばん上にあるタイトルをクリックすればその場で変更できます。

質問の横の「?」マークは何を表していますか？

左側の質問リスト

  • ? オレンジの白抜きの円 = まだ解決していない質問
  • ? 緑の塗りつぶしの円 = 解決した質問
  • 「?」を押すと解決済み／未解決が切り替わります。ツールバーの未解決のみをオンにすると、未解決の質問だけが表示されます。

タイムブロックの縦線

  • 色は解決状況（オレンジ／緑）を、塗りつぶしの円は回答が書かれていることを表します。
  • 「?」を押すと、その質問へ移動します。

整理する

タイムブロックと質問はどのように結びつきますか？

1つの講義に複数のタイムブロックを作れます。新しいブロックは作成した時刻から始まり、直前のブロックはその時刻までに期間が調整されます。

  • 質問は、その時点（なければ作成時刻）に合わせて、該当するブロックの縦線上に「?」で表示されます。
  • どのブロックにも含まれない時刻の質問があると、その時刻を含むブロックが自動で作られます。
  • ブロック右上の設定から、色・開始時刻・長さを変えたり、ブロックを削除したりできます。 ブロックを手動で削除した講義では、ブロックの自動作成が止まります（削除したブロックが再び作られないようにするためです）。
「追加の質問」とは？

1つの質問から派生した質問です。質問の詳細にある追加の質問欄に入力して Return を押すと作成できます。 既存の質問を追加の質問として関連づけるを使えば、すでにある質問をつなげることもできます。

左側のリストでは元の質問の下にインデントされて表示され、グラフでは矢印でつながります。関連づけを解除はつながりを外すだけで、質問そのものは削除しません。

「解決済み」と「学んだこと」はどう違いますか？

質問の詳細で解決済みにチェックを入れると、その質問を「学んだこと」に含めるかどうかを選べます。

まとめの「学んだこと」には、解決済みで、かつ「学んだこと」に含めた質問だけが集まります。まとめ画面の除外／元に戻すでも選べ、回答はそのまま残ります。

まとめ・グラフ・タイムブロック・学習状況はどこで見られますか？

ツールバーの表示メニューにまとまっています。

  • ⌘1 まとめ — 聞きたいこと、学んだこと、メモをひと目で
  • ⌘2 グラフ — 質問どうしの関係図。ノードを押すとその質問へ移動し、ピンチ操作や − / + で拡大・縮小、% を押すとウインドウに合わせます
  • ⌘3 タイムブロック — すべての講義のブロックを時系列で
  • ⌘4 学習状況 — いまの自分の状態 · 学び終えたときの自分の状態 · 学びたいこと
AIで答えを探すには？

質問の詳細で「回答」の見出しの右にあるAIプロンプトをコピーメニューからステップを選ぶと、講義名・その時点のメモ・学習状況・元の質問を埋め込んだプロンプトがクリップボードにコピーされます。 お使いのAIのチャット画面に貼り付けてください。

  • 質問を磨く → 答えを探す → 答えを問い直す → 追加の質問を引き出す → 自分の答えを採点してもらう
  • 「自分の答えを採点してもらう」は、回答欄に自分の言葉で書いた内容があるときに使えます。
  • アプリがAIサービスと直接通信することはありません。コピーと貼り付けはユーザー自身が行います。

詳しくはAIで答えを探すガイドをご覧ください。

会話のMarkdown（.md）を読み込むには？

講義名のメニュー → Markdownから読み込む… でファイルを選ぶと、新しい講義として作成されます。元のファイルは読み取るだけで、書き換えません。

# 講義のタイトル
## トピック 1
**自分** — 最初の質問（元の質問）
**AI** — 回答（回答欄に入り、解決済みになります）
**自分** — 続く質問（追加の質問）
  • ファイルで最初に登場する話者が質問者になり、それ以外の話者の発言は直前の質問への回答になります。
  • ## のセクションごとに、最初の質問が元の質問、続く質問がその追加の質問になります。

設定 · データ

文字の大きさを変えたい

表示 → 文字サイズで調整できます。⌘+ 大きく · ⌘- 小さく · ⌘0 標準サイズ（85%〜200%）。設定は保存されます。

質問や講義を削除するには？
  • 質問：左側のリストで質問を右クリック → 削除
  • 講義：講義名のメニュー → 現在の講義を削除（その講義の質問とブロックもあわせて削除されます）

削除は取り消せません。大切なデータは、先に下記の方法でバックアップしてください。

データはどこに保存されますか？ バックアップは？

データはすべてこのMac内の次のフォルダにだけ保存され、デバイスの外に送られることはありません。

~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/

  • バックアップ：アプリを終了してから、このフォルダを丸ごとコピーしてください（LectureQ.store と一緒にある -wal、-shm ファイルも含めて）。
  • 初期化：アプリを終了してから、このフォルダを削除してください。アプリをゴミ箱に入れるだけでは、このフォルダは削除されません。
動作環境 · ソースからビルドするには？

macOS 14以降で動作します。

ソースからのビルド：リポジトリをクローンして ./run.sh を実行するか、xcodegen generate のあと LectureQ.xcodeproj をXcodeで開いて実行してください。 詳しくはGitHubリポジトリをご覧ください。
