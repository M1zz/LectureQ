支援

使用 LectureQ 時如果有疑問或遇到問題，請先看看下面的說明。若仍無法解決，歡迎寄電子郵件與我們聯絡。

開始使用

要怎麼快速記下問題？

點一下工具列上藍色的新增問題按鈕，或隨時按下 ⌘ ⇧ N。

  • 時間點欄位會自動填入目前時刻。你可以依 HH:mm（24 小時制）格式修改，點一下現在即可重新設為目前時刻。
  • Return 儲存 · ⌘Return 儲存並繼續 · Esc 取消
要怎麼建立或切換課程？

在工具列左側的課程名稱選單中，可以選擇課程、新增課程、從 Markdown 匯入，或刪除目前課程。

點一下中間欄最上方的標題，就能直接修改課程名稱。

問題旁邊的「?」符號代表什麼？

左側問題列表

  • ? 橘色空心圓 = 還沒解決的問題
  • ? 綠色實心圓 = 已解決的問題
  • 點一下「?」即可在已解決／未解決之間切換。開啟工具列上的只看未解決，就只會顯示還沒解決的問題。

時間區塊的直線

  • 顏色代表是否已解決（橘色／綠色），實心圓代表已經寫了答案。
  • 點一下「?」就會前往該問題。

整理

時間區塊和問題是怎麼連結的？

一門課程可以建立多個時間區塊。新的時間區塊會從建立的時刻開始，上一個時間區塊的時長則會自動調整到該時刻為止。

  • 問題會依照它的時間點（沒有時間點就依建立時間），以「?」顯示在對應時間區塊的直線上。
  • 如果有問題的時間不落在任何時間區塊內，App 會自動建立一個涵蓋該時間的時間區塊。
  • 在時間區塊右上角的設定中，可以更改顏色、開始時間和時長，或刪除該時間區塊。 在曾手動刪除時間區塊的課程中，自動建立時間區塊的功能會停止（以免刪掉的時間區塊又冒出來）。
什麼是「追問」？

追問是從某個問題延伸出來的問題。在問題詳細資料的追問欄位輸入後按 Return 即可建立； 也可以透過將既有問題連結為追問，把已經存在的問題接上去。

在左側列表中，追問會縮排顯示在原問題下方；在關係圖中則以箭頭相連。解除連結只會切斷連結，不會刪除問題。

「已解決」和「學到的內容」有什麼不同？

在問題詳細資料中勾選已解決後，就可以選擇是否把這個問題列入「學到的內容」。

摘要裡的「學到的內容」只會收錄已解決、且已列入「學到的內容」的問題。在摘要畫面中也能用排除／重新加入來選擇，答案都會保留。

要在哪裡看摘要、關係圖、時間區塊和學習狀態？

它們都集中在工具列的檢視選單中。

  • ⌘1 摘要 — 待提的問題、學到的內容和筆記一目了然
  • ⌘2 關係圖 — 問題之間的關係圖。點一下節點就會前往該問題，用雙指撥動或點 − / + 來放大、縮小，點一下 % 即可符合視窗大小
  • ⌘3 時間區塊 — 依時間順序檢視所有課程的時間區塊
  • ⌘4 學習狀態 — 我現在的狀態 · 學完之後我想達到的狀態 · 我想學的內容
要怎麼用 AI 找答案？

在問題詳細資料中「答案」標題右側的拷貝 AI 提示詞選單裡選擇一個步驟，App 就會把已填好課程名稱、當時筆記、學習狀態和原問題的提示詞拷貝到剪貼簿。 把它貼到你慣用的 AI 對話視窗即可。

  • 梳理問題 → 尋找答案 → 反問答案 → 擷取追問 → 替我的答案打分數
  • 「替我的答案打分數」需要答案欄裡已經有你用自己的話寫下的內容才能使用。
  • App 不會直接與 AI 服務連線，拷貝和貼上都由你自己動手。

詳細做法請參考指南：用 AI 找答案。

要怎麼匯入對話的 Markdown（.md）檔？

在課程名稱選單 → 從 Markdown 匯入… 中選擇檔案，就會建立成一門新課程。App 只會讀取原始檔案，不會修改它。

# 課程標題
## 主題 1
**我** — 第一個問題（原問題）
**AI** — 回答（會填入答案並標示為已解決）
**我** — 接著的問題（追問）
  • 檔案中第一個出現的說話者是提問者，其他說話者的發言會成為上一個問題的答案。
  • 每個 ## 段落中，第一個問題是原問題，接著的問題就是它的追問。

設定 · 資料

想調整文字大小

在檢視 → 文字大小中調整。⌘+ 放大 · ⌘- 縮小 · ⌘0 預設大小（85%～200%）。設定會被儲存。

要怎麼刪除問題或課程？
  • 問題：在左側列表中對問題按右鍵 → 刪除
  • 課程：課程名稱選單 → 刪除目前課程（該課程的問題和時間區塊也會一併刪除）

刪除後無法復原，重要的資料請先依下面的方法備份。

我的資料存在哪裡？要怎麼備份？

所有資料都只會儲存在這部 Mac 的以下資料夾中，不會傳出裝置。

~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/

  • 備份：結束 App 後，把整個資料夾拷貝一份（包括和 LectureQ.store 放在一起的 -wal、-shm 檔案）。
  • 重置：結束 App 後，刪除這個資料夾。只把 App 丟到垃圾桶，並不會刪除這個資料夾。
系統需求 · 要怎麼從原始碼自行建置？

需要 macOS 14 或以上版本。

從原始碼建置：複製（clone）儲存庫後執行 ./run.sh，或先執行 xcodegen generate，再用 Xcode 開啟 LectureQ.xcodeproj 並執行。 詳情請參考 GitHub 儲存庫。
