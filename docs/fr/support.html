Assistance

Une question ou un problème avec LectureQ ? Consultez d’abord les réponses ci-dessous. Si vous ne trouvez pas de solution, écrivez-nous par e-mail.

Premiers pas

Comment noter rapidement une question ?

Cliquez sur le bouton bleu Ajouter une question dans la barre d’outils, ou appuyez à tout moment sur ⌘ ⇧ N.

  • Le champ Moment se remplit automatiquement avec l’heure actuelle. Vous pouvez le modifier au format HH:mm (24 h) ; Maintenant le remet à l’heure actuelle.
  • ↩ Enregistrer · ⌘↩ Enregistrer et continuer · Esc Annuler
Comment créer un cours ou en changer ?

Le menu des cours, à gauche de la barre d’outils, permet de choisir un cours, d’en ajouter un nouveau, d’en importer un depuis Markdown ou de supprimer le cours actuel.

Pour renommer un cours, cliquez directement sur son titre, en haut de la colonne centrale.

Que signifie le ? à côté d’une question ?

Dans la liste des questions, à gauche

  • ? Cercle orange vide = question pas encore résolue
  • ? Cercle vert plein = question résolue
  • Cliquez sur le ? pour passer de résolue à non résolue et inversement. Activez Non résolues uniquement dans la barre d’outils pour n’afficher que les questions en suspens.

Sur la ligne verticale des blocs horaires

  • La couleur indique si la question est résolue (orange / vert) ; un cercle plein signifie qu’une réponse a déjà été notée.
  • Cliquez sur le ? pour aller à cette question.

Organiser

Quel lien entre les blocs horaires et les questions ?

Un cours peut contenir plusieurs blocs horaires. Un nouveau bloc commence à l’heure où vous le créez, et le bloc précédent est ajusté pour se terminer à cette heure-là.

  • Chaque question s’affiche sous forme de ? sur la ligne verticale du bloc qui correspond à son moment (ou, à défaut, à son heure de création).
  • Si le moment d’une question ne tombe dans aucun bloc, un bloc qui le couvre est créé automatiquement.
  • Le bouton Réglages, en haut à droite d’un bloc, permet d’en changer la couleur, l’heure de début et la durée, ou de le supprimer. Dès que vous supprimez vous-même un bloc dans un cours, la création automatique de blocs s’arrête pour ce cours (afin que le bloc supprimé ne réapparaisse pas).
Qu’est-ce qu’une question de suivi ?

C’est une question qui découle d’une autre. Saisissez-la dans le champ Questions de suivi du détail de la question, puis appuyez sur ↩. Avec Lier une question existante comme question de suivi, vous pouvez aussi rattacher une question déjà créée.

Dans la liste de gauche, elle apparaît en retrait sous la question d’origine ; dans le graphe, elle y est reliée par une flèche. Dissocier supprime uniquement le lien, pas la question.

Quelle différence entre « Résolue » et « Ce que j’ai appris » ?

Quand vous cochez Résolue dans le détail d’une question, vous pouvez choisir de l’inclure dans « Ce que j’ai appris ».

La section « Ce que j’ai appris » du Résumé ne rassemble que les questions résolues que vous y avez incluses. Dans le Résumé, vous pouvez aussi utiliser Exclure / Réintégrer ; la réponse est toujours conservée.

Où trouver le résumé, le graphe, les blocs horaires et l’état d’apprentissage ?

Tout se trouve dans le menu Présentation.

  • ⌘1 Résumé : questions à poser, ce que vous avez appris et vos notes, d’un seul coup d’œil
  • ⌘2 Graphe : les liens entre vos questions. Cliquez sur un nœud pour aller à la question, pincez ou utilisez − / + pour zoomer, cliquez sur % pour ajuster à la fenêtre
  • ⌘3 Blocs horaires : les blocs de tous vos cours, dans l’ordre chronologique
  • ⌘4 État d’apprentissage : Où j’en suis maintenant · Où je veux en être à la fin · Ce que je veux apprendre
Comment trouver des réponses avec l’IA ?

Dans le détail de la question, à droite du titre « Réponse », choisissez une étape dans le menu Copier le prompt IA : un prompt rempli avec le nom du cours, les notes de ce moment-là, votre état d’apprentissage et la question d’origine est copié dans le presse-papiers. Collez-le dans la conversation de l’IA que vous utilisez.

  • Affiner la question → Trouver la réponse → Remettre la réponse en question → Dégager des questions de suivi → Faire noter ma réponse
  • « Faire noter ma réponse » n’est disponible que si le champ de réponse contient déjà un texte rédigé avec vos mots.
  • L’app ne communique pas elle-même avec les services d’IA : c’est vous qui copiez et collez.

Pour aller plus loin, consultez le Guide : trouver des réponses avec l’IA.

Comment importer une conversation au format Markdown (.md) ?

Dans le menu des cours, choisissez Importer depuis Markdown…, puis un fichier : un nouveau cours est créé. Le fichier d’origine est seulement lu, jamais modifié.

# Titre du cours
## Sujet 1
**Moi** — première question (question d’origine)
**IA** — réponse (devient la réponse, question marquée comme résolue)
**Moi** — question suivante (question de suivi)
  • La première personne qui parle dans le fichier est considérée comme celle qui pose les questions ; les propos des autres intervenants deviennent la réponse à la question précédente.
  • Dans chaque section ##, la première question est la question d’origine et les suivantes sont ses questions de suivi.

Réglages et données

Je voudrais changer la taille du texte.

Rendez-vous dans Présentation → Taille du texte : ⌘+ Plus grand · ⌘- Plus petit · ⌘0 Taille par défaut (de 85 % à 200 %). Le réglage est mémorisé.

Comment supprimer une question ou un cours ?
  • Question : dans la liste de gauche, clic droit sur la question → Supprimer
  • Cours : menu des cours → Supprimer le cours actuel (ses questions et ses blocs sont également supprimés)

La suppression est définitive : sauvegardez d’abord vos données importantes comme indiqué ci-dessous.

Où sont enregistrées mes données ? Comment les sauvegarder ?

Toutes vos données sont enregistrées uniquement dans le dossier suivant de ce Mac et ne quittent jamais l’appareil.

~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/

  • Sauvegarde : quittez l’app, puis copiez ce dossier en entier (y compris les fichiers -wal et -shm situés à côté de LectureQ.store).
  • Réinitialisation : quittez l’app, puis supprimez ce dossier. Placer l’app dans la corbeille ne suffit pas à l’effacer.
Configuration requise · Compiler l’app depuis le code source ?

L’app fonctionne sous macOS 14 ou version ultérieure.

Compilation : clonez le dépôt et lancez ./run.sh, ou exécutez xcodegen generate, puis ouvrez LectureQ.xcodeproj dans Xcode et lancez l’app. Plus de détails sur le dépôt GitHub.
