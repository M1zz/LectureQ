지원 (Support)

질문 노트 사용 중 궁금한 점이나 문제가 있으면 아래를 먼저 확인해 주세요. 해결되지 않으면 이메일로 연락해 주세요.

시작하기

질문을 빠르게 남기려면?

툴바의 파란 질문 추가 버튼을 누르거나, 언제든 ⌘ ⇧ N 을 누르세요.

  • 시점 칸에는 지금 시각이 자동으로 들어갑니다. HH:mm(24시간) 형식으로 고칠 수 있고, 지금을 누르면 다시 현재 시각으로 맞춰집니다.
  • Return 저장 · ⌘Return 저장하고 이어서 입력 · Esc 취소
강의를 만들거나 바꾸려면?

툴바 왼쪽의 강의 이름 메뉴에서 강의를 고르고, 새 강의를 추가하거나, 마크다운에서 가져오거나, 현재 강의를 삭제할 수 있습니다.

강의 이름은 가운데 열 맨 위의 제목을 눌러 바로 고칠 수 있습니다.

질문 옆의 ? 표시는 무슨 뜻인가요?

왼쪽 질문 목록

  • ? 주황 빈 원 = 아직 해결하지 못한 질문
  • ? 초록 꽉 찬 원 = 해결한 질문
  • ? 를 누르면 해결 / 미해결이 바뀝니다. 툴바의 미해결만을 켜면 해결하지 못한 질문만 보입니다.

타임블록 세로 줄

  • 색은 해결 여부(주황 / 초록), 꽉 찬 원은 답이 적혀 있다는 뜻입니다.
  • ? 를 누르면 그 질문으로 이동합니다.

정리하기

타임블록과 질문은 어떻게 연결되나요?

강의 하나에 여러 시간 블록을 만들 수 있습니다. 새 블록은 만든 시각에 시작하고, 직전 블록은 그 시각까지로 기간이 맞춰집니다.

  • 질문의 시점(없으면 작성 시각)에 맞춰 해당 블록의 세로 줄 위에 ? 로 표시됩니다.
  • 어느 블록에도 들지 않는 시각의 질문이 있으면, 그 시각을 담는 블록이 자동으로 만들어집니다.
  • 블록 오른쪽 위 설정에서 색상·시작 시각·기간을 바꾸거나 블록을 삭제할 수 있습니다. 블록을 직접 삭제한 강의에서는 자동 블록 생성이 멈춥니다(지운 블록이 다시 생기지 않도록).
꼬리질문(follow-up)이란?

하나의 질문에서 파생된 질문입니다. 질문 상세의 꼬리질문 칸에 입력하고 Return 을 누르면 만들어지고, 기존 질문을 꼬리질문으로 연결으로 이미 있는 질문을 이을 수도 있습니다.

왼쪽 목록에서는 원질문 아래에 들여쓰기로 보이고, 그래프에서는 화살표로 이어집니다. 해제는 연결만 끊고 질문은 지우지 않습니다.

‘해결됨’과 ‘배운 점’은 어떻게 다른가요?

질문 상세에서 해결됨을 체크하면, 그 질문을 배운 점에 포함할지 고를 수 있습니다.

요약의 ‘배운 점’에는 해결됐고 배운 점에 포함한 질문만 모입니다. 요약 화면에서 제외 / 다시 넣기로도 고를 수 있고, 답은 그대로 남습니다.

요약·그래프·타임블록·학습 상태는 어디서 보나요?

툴바의 보기 메뉴에 모여 있습니다.

  • ⌘1 요약 — 던질 질문, 배운 점, 메모를 한눈에
  • ⌘2 그래프 — 질문 관계도. 노드를 누르면 그 질문으로 이동, 핀치나 − / + 로 확대·축소, % 를 누르면 화면에 맞춤
  • ⌘3 타임블록 — 모든 강의의 블록을 시간순으로
  • ⌘4 학습 상태 — 지금 나의 상태 · 마쳤을 때 상태 · 배우고 싶은 것
AI로 답을 찾으려면?

질문 상세의 ‘답’ 제목 오른쪽 AI 프롬프트 복사 메뉴에서 단계를 고르면, 강의 이름·그 시점 메모·학습 상태·원질문이 채워진 프롬프트가 클립보드에 복사됩니다. 사용하는 AI 대화창에 붙여넣으세요.

  • 질문 다듬기 → 답 찾기 → 답 되묻기 → 꼬리질문 뽑기 → 내 답 채점받기
  • ‘내 답 채점받기’는 답 칸에 내 말로 적은 내용이 있어야 쓸 수 있습니다.
  • 앱이 AI 서비스와 직접 통신하지는 않습니다. 복사와 붙여넣기는 사용자가 직접 합니다.

자세한 방법은 AI로 답 찾기 가이드를 참고하세요.

대화 마크다운(.md)을 가져오려면?

강의 이름 메뉴 → 마크다운에서 가져오기… 에서 파일을 고르면 새 강의로 만들어집니다. 원본 파일은 읽기만 하고 바꾸지 않습니다.

# 강의 제목
## 주제 1
**나** — 첫 질문 (원질문)
**AI** — 답변 (답으로 들어가고 해결됨 처리)
**나** — 이어지는 질문 (꼬리질문)
  • 파일에 처음 등장하는 화자가 질문자, 그 밖의 화자 발화는 직전 질문의 답이 됩니다.
  • ## 섹션마다 첫 질문이 원질문, 이어지는 질문이 그 꼬리질문입니다.

설정 · 데이터

글씨 크기를 바꾸고 싶어요.

보기 → 글씨 크기에서 조절합니다. ⌘+ 크게 · ⌘- 작게 · ⌘0 기본 크기 (85% ~ 200%). 설정은 저장됩니다.

질문이나 강의를 지우려면?
  • 질문: 왼쪽 목록에서 질문을 우클릭 → 삭제
  • 강의: 강의 이름 메뉴 → 현재 강의 삭제 (그 강의의 질문과 블록도 함께 삭제됩니다)

삭제는 되돌릴 수 없으니, 중요한 데이터는 먼저 아래 방법으로 백업해 주세요.

내 데이터는 어디에 저장되나요? 백업은?

모든 데이터는 이 Mac 안의 다음 폴더에만 저장되며, 기기 밖으로 전송되지 않습니다.

~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/

  • 백업: 앱을 종료한 뒤 이 폴더를 통째로 복사하세요. (LectureQ.store 와 함께 있는 -wal, -shm 파일도 같이)
  • 초기화: 앱을 종료한 뒤 이 폴더를 삭제하세요. 앱을 휴지통에 버리는 것만으로는 이 폴더가 지워지지 않습니다.
시스템 요구 사항 · 소스에서 직접 빌드하려면?

macOS 14 이상에서 동작합니다.

소스 빌드: 저장소를 클론한 뒤 ./run.sh 를 실행하거나, xcodegen generate 후 LectureQ.xcodeproj 를 Xcode로 열어 실행하세요. 자세한 내용은 GitHub 저장소를 참고하세요.
