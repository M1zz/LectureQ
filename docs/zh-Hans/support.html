支持

使用 LectureQ 时如有疑问或遇到问题，请先查看下面的内容。如果仍未解决，欢迎发邮件联系我们。

快速上手

怎样快速记下一个问题？

点按工具栏上蓝色的添加问题按钮，或随时按下 ⌘ ⇧ N。

  • 时间点一栏会自动填入当前时刻。你可以按 HH:mm（24 小时制）格式修改，点按现在即可重新设为当前时刻。
  • Return 保存 · ⌘Return 保存并继续 · Esc 取消
怎样新建或切换课程？

在工具栏左侧的课程名称菜单中，可以选择课程、添加新课程、从 Markdown 导入，或删除当前课程。

点按中间栏最上方的标题，即可直接修改课程名称。

问题旁边的“?”标记是什么意思？

左侧问题列表

  • ? 橙色空心圆 = 尚未解决的问题
  • ? 绿色实心圆 = 已解决的问题
  • 点按“?”可在已解决／未解决之间切换。打开工具栏上的仅看未解决，就只会显示尚未解决的问题。

时间块竖线

  • 颜色表示是否已解决（橙色／绿色），实心圆表示已经写了答案。
  • 点按“?”即可前往该问题。

整理

时间块和问题是怎样关联的？

一门课程可以创建多个时间块。新时间块从创建的时刻开始，上一个时间块的时长会自动调整到这一时刻为止。

  • 问题会按照它的时间点（没有时间点则按创建时间），以“?”显示在对应时间块的竖线上。
  • 如果某个问题的时间不在任何时间块内，应用会自动创建一个包含该时间的时间块。
  • 在时间块右上角的设置中，可以更改颜色、开始时间和时长，或删除该时间块。 在手动删除过时间块的课程中，自动创建时间块的功能会停止（以免已删除的时间块再次出现）。
什么是“追问”？

追问是从某个问题延伸出来的问题。在问题详情的追问栏中输入并按 Return 即可创建； 也可以通过将已有问题关联为追问，把已经存在的问题接上。

在左侧列表中，追问会缩进显示在原问题下方；在关系图中，则以箭头相连。取消关联只会断开关联，不会删除问题。

“已解决”和“学到的内容”有什么区别？

在问题详情中勾选已解决后，可以选择是否把这个问题计入“学到的内容”。

摘要中的“学到的内容”只会汇总已解决、且已计入“学到的内容”的问题。在摘要画面中也可以用排除／重新加入来选择，答案都会保留。

在哪里查看摘要、关系图、时间块和学习状态？

它们都集中在工具栏的显示菜单中。

  • ⌘1 摘要 — 待提的问题、学到的内容和备注一目了然
  • ⌘2 关系图 — 问题之间的关系图。点按节点即可前往该问题，双指捏合或点按 − / + 进行放大、缩小，点按 % 即可适合窗口
  • ⌘3 时间块 — 按时间顺序查看所有课程的时间块
  • ⌘4 学习状态 — 我现在的状态 · 学完后我想达到的状态 · 我想学的内容
怎样用 AI 找答案？

在问题详情中“答案”标题右侧的复制 AI 提示词菜单里选择一个步骤，应用就会把填好课程名称、当时备注、学习状态和原问题的提示词复制到剪贴板。 把它粘贴到你常用的 AI 对话框里即可。

  • 梳理问题 → 寻找答案 → 反问答案 → 提取追问 → 给我的答案打分
  • “给我的答案打分”需要答案栏里已有你用自己的话写下的内容才能使用。
  • 应用不会直接与 AI 服务通信，复制和粘贴都由你自己完成。

详细方法请参阅指南：用 AI 找答案。

怎样导入对话的 Markdown（.md）文件？

在课程名称菜单 → 从 Markdown 导入… 中选择文件，即可将其创建为一门新课程。应用只读取原文件，不会修改它。

# 课程标题
## 主题 1
**我** — 第一个问题（原问题）
**AI** — 回答（会填入答案并标记为已解决）
**我** — 接着的问题（追问）
  • 文件中第一个出现的说话人是提问者，其他说话人的发言会成为上一个问题的答案。
  • 每个 ## 小节中，第一个问题是原问题，后面接着的问题是它的追问。

设置 · 数据

想调整文字大小

在显示 → 文字大小中调整。⌘+ 放大 · ⌘- 缩小 · ⌘0 默认大小（85%～200%）。设置会被保存。

怎样删除问题或课程？
  • 问题：在左侧列表中右键点按问题 → 删除
  • 课程：课程名称菜单 → 删除当前课程（该课程的问题和时间块也会一并删除）

删除后无法恢复，重要数据请先按下面的方法备份。

我的数据保存在哪里？怎样备份？

所有数据都只保存在这台 Mac 的以下文件夹中，不会传出设备。

~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/

  • 备份：退出应用后，把整个文件夹复制一份（包括与 LectureQ.store 放在一起的 -wal 和 -shm 文件）。
  • 重置：退出应用后，删除这个文件夹。仅把应用移到废纸篓并不会删除该文件夹。
系统要求 · 怎样从源代码自行构建？

需要 macOS 14 或更高版本。

从源代码构建：克隆仓库后运行 ./run.sh，或先执行 xcodegen generate，再用 Xcode 打开 LectureQ.xcodeproj 并运行。 详情请参阅 GitHub 仓库。
