## Review Notes

1. Screen recording
A screen recording captured on a physical device running the latest OS is attached to this submission. It starts from launching the app and shows the typical flow: creating a lecture, adding time blocks and notes, capturing a question, adding a follow-up and an answer, copying an AI prompt, the summary and graph views, the paywall, purchasing in the sandbox, and Restore Purchases.
The app has no account registration or login, so there is no account deletion flow. The app has no user-generated content that is shared with other users, so no reporting or blocking is needed.

2. Purpose and audience
LectureQ is a study notebook for students, self-learners and anyone attending lectures, classes, seminars or online courses.
Problem: questions that come up during a lecture are usually forgotten, or written down without the context of when they came up.
Value: with one tap (or Command-Shift-N on Mac) the user writes a question in plain words. It is stamped with the current time and kept beside the notes from that moment. Later the user finds the answer, adds follow-up questions, and marks what they learned, so the lecture turns into a review sheet.

3. How to use the main features
No login, demo account or sample file is needed. All features work offline right after launch.
a. Tap the plus button to create a lecture and give it a name.
b. Add a time block and type notes for that part of the lecture.
c. Tap the blue question button. The time is filled in automatically. Type a question and save.
d. Open the question to write an answer, mark it resolved, include it in what you learned, or add a follow-up question.
e. In the question detail, tap an AI prompt step. A prompt filled with the lecture name and notes is copied to the clipboard so the user can paste it into any AI service they already use. The app itself does not send anything to an AI service.
f. Use the View menu or tabs for Summary, Graph, Time Block overview and Learning State.

Paid features (In-App Purchase, StoreKit):
Free: up to 10 lectures, questions, notes, time blocks, the first two AI prompt steps, and the summary.
Plus: unlimited lectures.
Pro: everything in Plus, plus the remaining AI prompt steps, learning state, the question graph, the time block overview, Markdown import and Shortcuts/Siri.
Each tier is offered as a weekly, monthly or yearly auto-renewable subscription or a one-time lifetime purchase. Tip products are optional donations and unlock nothing.
To reach the paywall: create an 11th lecture, or tap a Pro feature such as Graph. Settings also contains the upgrade screen and Restore Purchases.

4. External services
Apple StoreKit for In-App Purchases and subscriptions.
Apple iCloud (CloudKit private database of the user's own iCloud account) to sync notes between the user's iPhone, iPad, Mac and Apple Vision Pro.
Apple CloudKit public database for anonymous, aggregated usage counts, optional feedback sent by the user, and remote feature switches. No personal data, note content or identifiers are collected.
No third-party SDKs, no authentication service, no ad network and no AI service are used. AI prompts are only copied to the clipboard.

5. Regional differences
The app works the same in all regions. Only the interface language and the local currency of In-App Purchase prices change.

6. Regulated industry or third-party material
Not applicable. The app is not in a regulated industry and contains no protected third-party content. All content is created by the user.
