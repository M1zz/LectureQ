지원 (Support)

LectureQ 사용 중 궁금한 점이나 문제가 있으면 아래를 확인하고, 해결되지 않으면 이메일로 연락해 주세요.

자주 묻는 질문

질문을 빠르게 남기려면?
언제든 ⌘ ⇧ N 을 누르면 질문 입력 창이 열립니다. Return 으로 저장, Esc 로 닫기, ⌘Return 으로 저장 후 계속 입력할 수 있습니다.
타임블록과 질문은 어떻게 연결되나요?
강의 하나에 여러 시간 블록을 만들 수 있고, 각 블록은 만든 시각에 시작해 다음 블록 전까지 이어집니다. 질문에 시각(예 14:30)을 적으면 해당 시각의 블록 위에 Q 버튼으로 표시되고, 블록 밖 시각이면 새 블록이 자동으로 만들어집니다. Q 버튼을 누르면 그 질문 상세로 이동합니다.
꼬리질문(follow-up)이란?
하나의 질문에서 파생된 질문을 꼬리질문으로 연결하면, 목록·상세·그래프에서 원질문 → 꼬리질문 위계로 보여집니다.
내 데이터는 어디에 저장되나요? 백업은?
모든 데이터는 ~/Library/Containers/com.lectureq.LectureQ/Data/Library/Application Support/LectureQ/ 폴더에 저장됩니다. 이 폴더를 통째로 복사하면 백업, 삭제하면 초기화됩니다. 데이터는 기기 밖으로 전송되지 않습니다.
글씨 크기를 바꾸고 싶어요.
툴바의 − aA + 버튼으로 앱 전체 글씨 크기를 조절할 수 있고, 설정은 저장됩니다.
소스에서 직접 빌드하려면?
macOS 14 이상 + Xcode에서, 저장소를 클론한 뒤 ./run.sh 를 실행하거나 xcodegen generate 후 LectureQ.xcodeproj 를 열어 실행하면 됩니다. 자세한 내용은 GitHub 저장소를 참고하세요.
